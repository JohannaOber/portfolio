PONS Langenscheidt GmbH·Work project·2026

The Language Coach

An AI-powered language learning platform delivering personalised, adaptive exercises for learners and full course management for teachers and admins.

My role

User research·Workshops·Stakeholder alignment·UX design

Topic

Human-AI-Interaction·Learner-Centered Design

Overview

01Problem

“Lost in the LLC universe”

Teachers, describing the platform

Many features had been added recently, and the navigation suffered. The whole system had become bloated, for learners, teachers and admins alike, and some users felt completely lost.

02Approach

Seeing the bigger picture

I zoomed out and looked at the whole platform: how roles and features connect, where the current problems lie and how the flow could be simplified. The goal was to make it simpler and clearer for every user group.

03Result

More clarity, more users

Features found their place, navigation became more intuitive and onboarding was refined. After launch, together with a B2C marketing push, metadata showed a growing user base and rising subscriptions. Teachers in particular appreciate contributing directly to the design process.

Main decisions

01

Navigation before new features

Navigation problems had been the dominant theme in feedback across several quarters, so the structure came first.

Trade-off: further feature requests moved to later releases, but they were already considered in the new navigation.

02

All three roles in one redesign

Every flow was simplified and then aligned with the other roles and their flows, so that learners, teachers and admins share one coherent system instead of separate parts.

03

A vibe-coded prototype for testing

The vibe-coded prototype let the focus stay on UX: usability issues could be fixed right after each session, and variants were A/B tested within the same phase instead of in the next cycle.

Full process

Navigation issues had been building across quarters. Teachers described feeling “lost in the LLC universe”, unable to orient themselves across multiple platforms. Learners struggled equally, finding the structure of the learning platform unclear. These insights made navigation the focus of the next research cycle.

All three roles, learner, teacher and admin, were reworked. Based on research and workshop results, I sketched flow variants and feature priorities, aligned them with stakeholders, and moved into design sprints.

I explored and compared multiple flow variants for all three roles, weighing pros and cons before committing to a direction. The chosen flows were then translated into high-fidelity designs using a newly built component library, aligned with the company’s updated CI.

Each flow was tested with real users, both long-term testers and new ones, using A/B testing to measure qualitative differences early. A vibe-coded prototype allowed usability issues to be fixed immediately after each session and variants to be tested flexibly within the same phase.
