Akkodis·Internal project·2024

HMI for Driving Simulation

A modular, brand-aligned EV cockpit interface built for Akkodis's internal driving simulation software.

My role

Benchmarking·HMI design·Component library·States and variants

Topic

Automotive·HMI

Overview

01Problem

Customer-tailored simulations

Akkodis needed a generic electric vehicle HMI to demonstrate their driving simulation software to potential clients. The interface had to reflect the Akkodis brand, cover all essential EV functions, and be fully modular for animation, signal integration, and 3D vehicle extensions.

02Approach

White-label components

I benchmarked existing EV cockpit interfaces to define the essential elements for a credible simulation environment. Each HMI element was designed as a standalone component, provided in multiple states and transparency levels to cover the different simulation use cases, and reviewed against the simulation team's technical requirements before handoff.

03Result

Modular and brand-ready

The result is a complete EV HMI component library in a clean, Akkodis-branded interface, ready for animation, signal input, and 3D integration. It streamlined the simulation team's animation workflow and serves as a base product for client demonstrations.

My role

As the sole designer, my tasks were:

  • Benchmarking
  • HMI design
  • Component library
  • States and variants
  • Handoff
